이 강의의 핵심 흐름은 다음과 같습니다.

> 사람이 특징을 설계 → CNN이 특징을 스스로 학습 → 더 깊게 쌓음 → 깊이의 벽 → ResNet의 Skip Connection → 언어에서는 RNN의 순서의 벽 → LSTM → Seq2Seq의 고정 벡터 병목 → Attention → RNN의 순차성까지 제거 → Transformer

즉, 이 강의에서 계속 반복되는 핵심 질문은 하나입니다.

> "정보와 학습 신호가 앞뒤로 잘 흐르도록 어떻게 구조를 설계할 것인가?"

## 1. 이미지 분야

**CNN**

- 사람이 "가장자리, 곡선" 같은 특징을 직접 설계하지 않고 신경망이 직접 학습
- 작은 필터를 이미지 전체에 반복 적용
- 같은 필터를 공유하므로 파라미터를 크게 줄임

**2012년 AlexNet**

- 대규모 데이터 + GPU + CNN이 결합
- ImageNet에서 기존 방법을 크게 앞서며 딥러닝 부활의 계기가 됨
- ReLU, Dropout, GPU 등이 중요한 역할

**VGG / GoogLeNet**

- "더 깊게 쌓자"는 방향으로 발전, 2014년 VGG, GoogLeNet 등장
- 문제: **Vanishing Gradient** — 너무 깊어지면 역전파 과정에서 기울기가 점점 작아져 앞쪽 층까지 학습 신호가 제대로 전달되지 않음

**ResNet**

- Skip Connection을 사용해 일부 층을 건너뛰는 지름길을 만듦 — `F(x) + x`
- 층 전체를 학습하는 대신 입력과 출력의 차이인 Residual을 학습
- 깊은 네트워크도 안정적으로 학습 가능

## 2. 언어 분야의 발전

이미지와 달리 언어에는 순서가 중요했습니다. 예를 들어 "학생이 교사를 칭찬했다"와 "교사가 학생을 칭찬했다"는 단어는 비슷하지만 순서가 다르면 의미가 달라집니다.

**Word2Vec**: 단어를 단순한 번호가 아니라 의미 관계를 가진 벡터로 변환. "어떤 단어의 의미는 주변에 어떤 단어가 등장하는가에 나타난다." 그래서 비슷한 문맥에서 사용되는 단어는 비슷한 벡터를 갖게 됨.

**RNN**: 문장을 앞에서부터 한 단어씩 읽고, 지금까지 읽은 내용을 hidden state에 담아 다음 단계로 전달. 문제는 문장이 길어지면 앞쪽 정보가 점점 희미해짐 — **언어의 순서의 벽**.

**LSTM**: RNN에 cell state + gate(입력 게이트, 망각 게이트, 출력 게이트)를 추가. 무엇을 기억하고 무엇을 버릴지 조절하면서 장거리 정보를 더 잘 전달.

**Seq2Seq**: Encoder가 문장을 읽고 문장 전체를 context vector 하나로 압축, Decoder가 이 벡터를 이용해 새로운 문장을 생성. 문제는 긴 문장을 벡터 하나에 담아야 한다는 것 — **Fixed-Vector Bottleneck**.

## 3. Attention의 등장

해결 방법은 아주 직관적입니다. "왜 문장 전체를 벡터 하나에 넣어야 하지?" — Decoder가 필요할 때마다 원문의 단어들을 직접 다시 보게 하면 됩니다. 이것이 **Attention**입니다.

번역할 때 원문의 모든 단어를 보고 "지금 어떤 단어가 중요한가?"를 계산 — 압축해서 기억하는 방식 → 필요한 정보를 직접 찾아보는 방식으로 바뀐 것입니다.

## 4. Transformer

"Attention이 이렇게 중요한데, 굳이 RNN이 있어야 할까?" — 그래서 2017년 **Transformer**가 등장합니다. 핵심은 RNN의 순차 처리 없이 Attention만으로 문장을 처리하자는 것.

그 결과: 순차 처리 제거 → 병렬 계산 가능 → GPU 활용 증가 → 더 큰 데이터와 모델을 학습 가능. 이것이 현재 LLM으로 이어지는 중요한 출발점이 됩니다.

## 5. Transformer의 핵심 구조 — Q / K / V

Attention을 이해하는 가장 중요한 세 단어입니다. 과정은: Q와 K를 비교 → 중요도를 계산 → 그 중요도만큼 V를 가져옴. 즉 "지금 이 단어를 이해하려면 다른 단어를 얼마나 참고해야 하는가?"를 계산하는 것입니다.

| 개념 | 의미 | 비유 |
|---|---|---|
| Query | 내가 무엇을 찾는가 | 질문 카드 |
| Key | 나는 어떤 정보와 관련 있는가 | 책의 색인 |
| Value | 실제 가져올 정보 | 책 내용 |

## 6. Multi-Head Attention

하나의 관점만 보는 것이 아니라 여러 관점에서 동시에 봅니다. 예를 들어 한 head는 주어-동사 관계를 볼 수 있고, 다른 head는 단어 간 의미 관계를 볼 수 있다는 식입니다. (실제 head가 사람이 정한 역할대로 정확히 작동한다는 의미는 아니지만, 여러 관점에서 동시에 관계를 보는 구조라고 이해하면 됩니다.)

## 7. Position Encoding

Attention만 사용하면 "누가 누구와 관련 있는가?"는 알지만 "누가 먼저 나왔는가?"는 스스로 알지 못합니다. 그래서 위치 정보를 넣어줍니다. 대표적으로 Sinusoidal, Learned Position Embedding, RoPE, ALiBi 등이 있습니다.

## 8. KV Cache / MHA / MQA / GQA

생성형 모델은 토큰을 하나씩 생성하기 때문에 이전 토큰의 K와 V를 매번 다시 계산하면 비효율적입니다. 그래서 계산한 K와 V를 저장해두는 것이 **KV Cache**입니다.

K/V를 몇 개의 Query Head가 공유할지에 따라:

- **MHA**: 각각 따로 사용
- **MQA**: 여러 Query가 하나의 K/V 공유
- **GQA**: 여러 Query를 그룹으로 묶어 일부 K/V 공유

핵심은 성능과 메모리 효율 사이의 균형입니다.

## 9. 가장 중요한 연결고리

이번 강의에서 제일 중요한 것은 모델 이름을 외우는 것이 아니라 **문제 → 해결 구조**를 연결하는 것입니다. 이 표를 기억하면 이번 강의의 대부분을 설명할 수 있습니다.

| 문제 | 발생한 곳 | 해결 |
|---|---|---|
| 사람이 특징을 직접 설계해야 함 | 초기 컴퓨터 비전 | CNN |
| 더 깊게 만들수록 학습 신호가 약해짐 | CNN | ResNet / Skip Connection |
| 긴 문장에서 앞 정보가 사라짐 | RNN | LSTM |
| 문장 전체를 벡터 하나에 압축 | Seq2Seq | Attention |
| RNN의 순차 처리 | RNN + Attention | Transformer |
| 위치 정보를 모름 | Transformer | Positional Encoding |
| 긴 생성 과정에서 K/V 재계산 | Transformer | KV Cache |

## 10. 용어 정리

- **CNN (Convolutional Neural Network)**: 이미지의 국소적인 패턴을 필터로 찾아내며 특징을 학습하는 신경망
- **Convolution**: 필터를 이미지의 여러 위치에 적용해 특징을 계산하는 연산
- **ReLU**: 음수는 0, 양수는 그대로 통과시키는 활성화 함수 (`ReLU(x) = max(0, x)`). 비선형성을 넣어 깊은 신경망이 복잡한 패턴을 학습할 수 있게 함
- **Dropout**: 학습 과정에서 일부 뉴런을 무작위로 끄는 방법. 주요 목적은 과적합 방지
- **과적합**: 훈련 데이터는 매우 잘 맞히지만 새로운 데이터에서는 성능이 떨어지는 현상
- **Vanishing Gradient**: 역전파 과정에서 기울기가 계속 작아져 앞쪽 층까지 학습 신호가 거의 전달되지 않는 현상
- **Skip Connection**: 일부 층을 건너뛰고 입력 정보를 직접 다음 층으로 전달하는 연결
- **Residual**: 목표 출력 H(x)와 입력 x의 차이 (`F(x) = H(x) - x`). ResNet은 이 차이를 학습
- **Embedding**: 단어 등의 대상을 의미 관계가 담긴 벡터로 표현한 것
- **Word2Vec**: 단어의 주변 문맥을 이용해 단어 벡터를 학습하는 방법
- **RNN**: 이전 단계의 정보를 다음 단계로 전달하면서 순서 데이터를 처리하는 신경망
- **Hidden State**: RNN이 지금까지 읽은 내용을 요약하여 가지고 가는 작업 기억
- **LSTM**: RNN의 장기 기억 문제를 해결하기 위해 별도의 기억 통로와 게이트를 사용하는 구조
- **Seq2Seq**: Encoder가 입력을 읽고 Decoder가 출력을 생성하는 구조
- **Context Vector**: Seq2Seq에서 입력 문장 전체를 압축해서 담은 벡터
- **Fixed-Vector Bottleneck**: 아무리 긴 입력도 고정 크기의 벡터 하나에 압축해야 하는 문제
- **Attention**: 현재 필요한 정보를 얻기 위해 입력의 어느 부분을 얼마나 참고할지 계산하는 메커니즘
- **Transformer**: RNN이나 CNN 없이 Attention을 중심으로 문장을 처리하는 구조
- **Query**: 현재 토큰이 찾고자 하는 정보
- **Key**: 각 토큰이 어떤 정보와 관련 있는지를 나타내는 기준
- **Value**: 실제로 가져오는 정보
- **Multi-Head Attention**: 여러 개의 Attention을 동시에 적용해 다양한 관계를 학습하는 구조
- **Positional Encoding**: 토큰의 순서와 위치 정보를 모델에 알려주는 방법
- **Causal Mask**: 생성 시 미래 토큰을 보지 못하도록 막는 장치
- **KV Cache**: 이전에 계산한 Key와 Value를 저장해 생성 속도를 높이는 메모리 구조
- **MHA (Multi-Head Attention)**: 각 Query Head가 별도의 K/V Head를 사용하는 방식
- **MQA (Multi-Query Attention)**: 여러 Query Head가 하나의 K/V를 공유하는 방식
- **GQA (Grouped-Query Attention)**: Query Head를 그룹으로 묶고 각 그룹이 일부 K/V를 공유하는 절충 방식
