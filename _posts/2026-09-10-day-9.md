## AI의 원리

- **인공지능**
- **머신러닝** ⇒ 사람이 직접 특징을 뽑아냄 → 이것들을 넘겨서 데이터를 얻어냄
- **딥러닝** ⇒ 스스로 직접 특징을 추출해서 학습을 함

예) 사과 사진을 특징과 함께 "잘 익었는지"까지의 정답을 넘겨서 학습 ⇒ 머신러닝. 사과 사진만 넘겨서 "잘 익은 사과다"라고 하면 잘 익은 사과의 특징을 스스로 학습 ⇒ 딥러닝

**퍼셉트론** ⇒ 인간의 뉴런을 모방

## 데이터를 숫자로 바꾸기

AI에 입력되는 데이터는 다 숫자여야 함.

**문장을 숫자로 바꾸는 법**

- 컴퓨터가 알아들을 수 있는 단위(토큰)로 잘라서 숫자로 변환
- 단순한 숫자가 아닌 벡터로 바꿈

| 단위 | 의미 |
|---|---|
| 스칼라 | 숫자 하나 |
| 벡터 | 숫자가 일렬로 나열 |
| 매트릭스 | 벡터가 쌓임 |
| 텐서 | 매트릭스가 3차원 이상으로 쌓임 |

언어모델은 각 토큰을 벡터화시켜서 입력으로 집어넣음. 이 값을 표로 표시했을 때 단어 사이가 얼마나 가까운지를 체크 — 단어 사이의 관계를 가지고 AI가 문장을 파악하고, 출력할 때도 그 관계를 고려함. ⇒ 가까울수록 연관 있는 단어, 멀수록 연관 없는 단어

## 프로그래밍 기초

- 참: `1`, `True`
- 거짓: `0`, `false`

## 모델의 학습

숫자로 바뀐 데이터들은 신경망에 들어가 **예측 → 오차 → 조정**이 이루어짐. 한 층에 들어온 숫자들에 가중치를 곱해 입력의 중요도를 반영.

> 가중치: 특정 정보가 결과에 얼마나 중요한 영향을 미치는지 나타내는 중요도. 최종 판단을 내릴 때 더 중요한 요소의 비중을 더 높게 곱해주는 수치.

**실제 AI 학습 방식 (경사하강법)**

1. 처음에 무작위(랜덤) 가중치로 시작
2. 예측값과 정답을 비교하여 오차(틀린 정도)를 계산
3. 수학적 계산(미분)을 통해 "가중치를 어느 방향으로, 얼마나 줄이거나 늘려야 오차가 줄어드는지" 방향을 알아냄
4. 그 방향으로 가중치를 아주 조금씩 수정(업데이트)

⇒ 학습이 끝나면, 그동안 쌓인 데이터 학습을 통해 가장 정답을 잘 맞히게 된 최적의 가중치 수치들이 최종 모델 데이터로 저장됨.

학습을 할 때 업데이트되는 항목은 w, b 값. 오차로부터 계산을 거슬러 올라가서 w, b를 어떻게 조정하면 오차가 줄어들지 흐름으로 조정하고 반복함.

```
파란점 - 수집한 데이터
빨간 선 - AI로 학습시킨 데이터
```

학습이 되면 될수록 오차가 줄어드는 그래프가 나옴.

## GPU와 CPU

딥러닝에 왜 GPU가 필요할까?

- **CPU**: 복잡한 작업을 순차적(직렬)으로 → 한 번에 하나의 일만 처리 → 복잡한 계산 가능
- **GPU**: 단순하고 반복적인 작업을 동시에(병렬) → 처리속도가 빠름 → 복잡한 계산은 못함

AI 학습할 때는 GPU가 반드시 필요 (훨씬 빠름).

## 모델 깊이와 ResNet

레이어가 많을수록 "깊은 모델"이라고 표현. 깊게 쌓을수록 복잡한 문제를 풀 수 있고, 데이터가 풍부하고 복잡할수록 깊어질수록 성능이 좋아지는 게 정상이지만, 어느 순간 깊게 쌓아도 성능이 더 좋아지지 않는 현상이 나옴.

레이어가 깊어졌더니 역으로 계산해 올라갈 때 최종 지점인 인풋값에 다다를수록 뭘 계산하고 있었는지 잊어버리는 현상 ⇒ 레이어가 깊을수록 오히려 안 좋아질 수도 있다는 것을 발견. 이를 개선하기 위한 방안 = **ResNet** — 중간중간 건너뛰어가는 방식.
