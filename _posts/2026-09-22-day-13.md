## 프로젝트: 영상·음향 멀티모달 이상 탐지 PoC

**목표:** 영상과 음향 데이터를 각각 분석한 뒤 결과를 결합하여, 사람이 직접 영상을 처음부터 끝까지 확인하지 않아도 이상이 발생한 것으로 의심되는 구간을 자동으로 찾아낸다.

## PoC 전체 구조

```
입력 영상
                       │
              ┌────────┐
              ↓                 ↓
          영상 분석           음향 분석
              │                 │
         YOLO / CV           Whisper
              │                 │
      객체·장면 정보       대사·음성 구간
              │                 │
              └────────┘
                       ↓
                시간축 정렬
                       ↓
              멀티모달 정보 결합
                       ↓
                 이상 탐지
                       ↓
              ┌───┴────┐
              ↓                 ↓
          영상 이상          음향 이상
              │                 │
              └───┬────┘
                       ↓
                 QC 리포트
```

## PoC에서 증명할 것

이번 과제에서는 딱 세 가지를 증명하면 돼.

① 영상에서 의미 있는 정보를 뽑을 수 있는가?
② 음향에서 의미 있는 정보를 뽑을 수 있는가?
③ 둘을 합치면 이상 탐지가 더 의미 있어지는가?

> "영상 + 음향 정보를 결합해 QC 후보 구간을 찾아내는 것이 가능하다"

## 실험 설계 — 오히려 PoC라면 이런 실험을 해보는 게 좋아

**실험 1. 영상만 사용**

```
영상
 ↓
YOLO / 프레임 분석
 ↓
이상 후보
```

결과: 영상만으로는 이런 이상을 발견할 수 있었다.

**실험 2. 음향만 사용**

```
음향
 ↓
Whisper + 음향 분석
 ↓
이상 후보
```

결과: 음향만으로는 이런 이상을 발견할 수 있었다.

**실험 3. 영상 + 음향**

```
영상 ─┐
      ├→ 시간축 결합 → 이상 탐지
음향 ─┘
```

결과: 영상과 음향을 함께 사용했을 때 어떤 추가 정보를 얻을 수 있었는지 확인한다.

이렇게 하면 멀티모달을 왜 사용하는지까지 실험으로 보여줄 수 있어.

## 최종 PoC 구성

```
1. 데이터 수집
       ↓
2. 데이터 라벨링
       ↓
3. 영상/음향 전처리
       ↓
4. AI 모델 적용
       ↓
5. 영상 + 음향 결과 결합
       ↓
6. 이상 탐지
       ↓
7. 성능 평가
       ↓
8. 실패 사례 분석
       ↓
9. QC 리포트
```

## 다음 단계별 진행

### 1단계 — 문제 정의서 작성

도메인/현재 문제/개선 가설/대상 사용자/성공 기준을 문서로 먼저 씁니다. 예시로 성공 기준은 "라벨링한 정답 구간 대비 자동 탐지 recall/precision", 또는 "수작업 20분 전체 시청 → PoC로 이상 후보만 2분 검토"처럼 숫자로 잡는 게 좋습니다.

### 2단계 — 데이터 수집 (직접 촬영)

영상 5~10개, 각 30초~2분 내외로 촬영하되 각 영상 안에 정상 구간 + 의도적으로 심은 이상 구간을 섞어서 찍는 게 핵심입니다. 예:

- 정상적으로 말하는 구간
- 입은 움직이는데 소리를 죽이거나 다른 음성을 더빙해 끼워 넣은 구간 (립싱크 불일치 재현)
- 화면 밖으로 나가거나 뒤돌아 있는데 대사가 나오는 구간 (화자 부재 발화)
- 중간에 음소거/무음 구간 삽입 (드롭아웃)

촬영과 동시에 어느 구간이 몇 초~몇 초에 어떤 이상인지 직접 기록해두세요. 이게 나중에 성능 평가할 정답지(ground truth)가 됩니다.

### 3단계 — 라벨링

영상별로 `(start_sec, end_sec, anomaly_type)` 형태의 CSV를 만듭니다. 촬영할 때 메모한 걸 정리하면 됩니다.

### 4단계 — 전처리

- ffmpeg로 오디오 분리(wav, 16kHz mono) + 프레임 추출(초당 1~5프레임 정도로 다운샘플, 굳이 30fps 다 볼 필요 없음)
- 로컬에 ffmpeg가 없어서 설치가 필요합니다 (아래 명령 참고)

### 5단계 — 영상 분석 모듈 (YOLO)

YOLO(ultralytics yolov8n 또는 얼굴 검출 특화 가중치)로 프레임마다 얼굴을 검출 → 얼굴 박스의 아래쪽 1/3(입 주변)을 잘라 프레임 간 픽셀 변화량(간단한 optical flow/frame diff)을 측정 → "이 초에 입이 움직이고 있었는가"를 시계열 신호로 만듭니다.

### 6단계 — 음향 분석 모듈 (Whisper)

audio model test/transcribe.py에 이미 Whisper 사용 이력이 있으니 그 경험을 재사용하면 됩니다. Whisper로 STT + 세그먼트 타임스탬프를 뽑아 "이 초에 대사가 있었는가" 신호를 만들고, 에너지 기반 무음 구간도 같이 체크합니다.

### 7단계 — 시간축 정렬 + 결합

두 신호를 초 단위로 리샘플링해서 하나의 표로 합칩니다: 시간 | 입움직임여부 | 발화여부. 규칙은 단순하게 시작하세요 — 예: "N초 이상 지속되는 불일치(입O/음성X 또는 입X/음성O)"를 이상 후보로 표시. 처음부터 복잡한 통계 모델 쓸 필요 없습니다.

### 8단계 — 실험 설계 (제출물의 핵심)

- 실험1: 영상 신호만으로 이상 탐지 → 결과 기록
- 실험2: 음향 신호만으로 이상 탐지 → 결과 기록
- 실험3: 결합 → 결과 기록, 실험1·2 대비 뭐가 더 잡혔는지/오탐이 줄었는지 비교

### 9단계 — 성능 평가 + 실패 사례 분석

라벨(정답) vs 탐지 결과로 precision/recall 계산. 오탐/미탐 사례를 스크린샷과 함께 몇 개 뽑아서 왜 틀렸는지 설명 (예: 손으로 입을 가린 순간을 "발화 없음"으로 오인).

### 10단계 — QC 리포트 생성

이상 후보 구간마다 타임스탬프 + 해당 프레임 캡처 + 판단 근거를 markdown/html로 자동 출력하는 스크립트.

## 오늘의 메모

실제 촬영 본 대신 인터넷 인터뷰 영상으로 대체.
