좌표값이 출력으로 나옴.

## 세그멘테이션 (분할)

픽셀 하나하나에 대해서 어떤 클래스에 속하는지를 찾는 것 — 픽셀 하나하나마다 클래스를 구분.

**출력 방법**: 이미지 한 장에 픽셀별로 해당 클래스에 대한 숫자가 들어감 ⇒ 이렇게 한 장짜리 이미지를 만듦.

**구분 방법**

- **semantic segmentation**: 세 종류의 클래스가 있다면 세 가지로만 구분
- **instance segmentation**: 객체를 구분, 배경은 구분하지 않음
- **파놉틱(panoptic)**: 객체와 배경까지 구분 — 오브젝트 따로, 배경도 따로 (엄밀히 말하면 위 semantic/instance 예시 그림들도 파놉틱이라고 할 수 있음)

경계가 결정되는 것은 사람이 학습데이터로 만들었기 때문.

## 성능 지표

### IoU

정답지와 모델이 추론한 것이 얼마나 겹치는가 = 겹치는 영역 / 전체 영역. 높을수록 성능이 좋음.

### AP / mAP

AI 출력 결과는 정확하게 0, 1로 떨어지는 것이 아님 → 근사치로 판단. 판단 기준(확률 필터)을 사람이 설정하며, 상황에 맞게 조절해야 함.

**Precision (정밀도)**: 모델이 예측했던 것 중에 실제 정답지를 봤을 때 맞는 것 = 모델이 예측했던 것들 중에서 실제 정답인 비율.
예) 모델이 스팸메일이라고 예측했던 것들 중 실제 스팸메일인 것

**Recall (재현율)**: 모델이 예측했던 것에서 판단하는 게 아니라, 실제 내가 준비한 데이터들 중에서 정답인 것들 중 모델이 맞춘 비율.
예) 내가 준비한 스팸메일 중 모델이 맞춘 스팸메일 비율

각 필터링 기준(확률)을 0에서부터 점점 높이면 값이 계속 달라짐. AP가 높을수록 모델의 성능이 좋음. **mAP**는 이를 평균낸 값.

## UV

패키지 관리 소프트 / 가상환경 관리. 속도가 매우 빠름.

**가상화 패키지 관리**: 프로그램 A에는 numpy 2.0, 프로그램 B에는 numpy 1.12가 깔려있다면, 각 프로그램별로 가상환경을 만들어서 프로그램이 돌아갈 수 있게 함.
